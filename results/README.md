## 1_data_cleaning

**Generated by:** `scripts/1_data_cleaning.r`

This folder contains cleaned and quality-checked feed and water visit data, along with daily summaries and quality control warnings.

### Files:

#### `summary_df.csv`
Daily summary statistics for each animal, combining feed and water intake data.

**Columns:**
- `date`: Date of observation (YYYY-MM-DD format)
- `cow`: Animal ID
- `feed_intake`: Total daily feed intake (kg)
- `feed_duration`: Total daily time spent feeding (seconds)
- `feed_visits`: Total number of feed bin visits per day
- `water_intake`: Total daily water intake (kg)
- `water_duration`: Total daily time spent drinking (seconds)
- `water_visits`: Total number of water bin visits per day

#### `warnings.csv`
Quality control warnings and flags detected during data cleaning for each day.

**Columns:**
- `date`: Date of observation (YYYY-MM-DD format)
- `total_cows`: Total number of animals observed on this day
- `missing_cow`: List of animal IDs that were expected but missing
- `double_detection_bins`: Bins with double detection issues (same animal detected at multiple bins simultaneously)
- `negative_visit_bins`: Bins with negative visit durations or intake values
- `cows_disappeared_after_noon`: Animal IDs that stopped appearing in data after noon
- `bins_never_visited`: Bin IDs that were never visited on this day
- `bins_low_traffic`: Bin IDs with unusually low visit counts
- `long_dur_feeder`: Feed bins with visits exceeding maximum duration threshold
- `large_intake_feed_visit`: Feed visits with unusually large intake amounts
- `low_daily_feed_intake_cows`: Animal IDs with daily feed intake below expected minimum
- `high_daily_feed_intake_cows`: Animal IDs with daily feed intake above expected maximum
- `long_dur_drinker`: Water bins with visits exceeding maximum duration threshold
- `large_intake_water_visit`: Water visits with unusually large intake amounts
- `low_daily_water_intake_cows`: Animal IDs with daily water intake below expected minimum
- `high_daily_water_intake_cows`: Animal IDs with daily water intake above expected maximum

#### `clean_feed.rda`
R data file containing cleaned feed visit data (list of data frames, one per day).

**Structure:** List of data frames, where each data frame contains:
- `transponder`: Transponder ID
- `cow`: Animal ID
- `bin`: Feed bin number (1-30)
- `start`: Visit start time (POSIXct datetime)
- `end`: Visit end time (POSIXct datetime)
- `duration`: Visit duration (seconds)
- `start_weight`: Feed weight at start of visit (kg)
- `end_weight`: Feed weight at end of visit (kg)
- `intake`: Feed intake during visit (kg)
- `date`: Date of visit (Date format)
- `rate`: Feeding rate (kg/second)

#### `clean_water.rda`
R data file containing cleaned water visit data (list of data frames, one per day).

**Structure:** List of data frames, where each data frame contains:
- `transponder`: Transponder ID
- `cow`: Animal ID
- `bin`: Water bin number (101-105, with bin_offset = 100)
- `start`: Visit start time (POSIXct datetime)
- `end`: Visit end time (POSIXct datetime)
- `duration`: Visit duration (seconds)
- `start_weight`: Water weight at start of visit (kg)
- `end_weight`: Water weight at end of visit (kg)
- `intake`: Water intake during visit (kg)
- `date`: Date of visit (Date format)
- `rate`: Drinking rate (kg/second)

#### `clean_comb.rda`
R data file containing combined cleaned feed and water visit data (list of data frames, one per day).

**Structure:** List of data frames combining feed and water visits with the same columns as `clean_feed.rda` and `clean_water.rda`.

## 2_meal_clustering

**Generated by:** `scripts/2_meal_clustering.r`

This folder contains meal clustering results, where individual feed visits are grouped into meals based on time gaps between visits.

### Files:

#### `gmm_gap_distribution.png`
Visualization showing the distribution of time gaps between consecutive feed visits and the Gaussian Mixture Model (GMM)-based meal interval threshold (eps).

**Description:** This plot helps visualize the optimal meal interval threshold used for clustering visits into meals. It shows:

- Histogram of time gaps between consecutive visits (log-transformed)
- GMM components fitted to the gap distribution
- The automatically determined meal interval threshold (eps) that separates within-meal gaps from between-meal gaps

#### `meal_summaries.csv`
Summary statistics for each identified meal.

**Columns:**
- `cluster`: Cluster/meal identifier (numeric)
- `cow`: Animal ID
- `date`: Date of meal (YYYY-MM-DD format)
- `meal_id`: Unique meal identifier within the day for this animal
- `meal_start`: Start time of the meal (POSIXct datetime)
- `meal_end`: End time of the meal (POSIXct datetime)
- `meal_duration`: Total duration of the meal (seconds)
- `visit_count`: Number of feed bin visits included in this meal
- `total_intake`: Total feed intake during the meal (kg)
- `unique_bins_count`: Number of unique feed bins visited during the meal
- `feeding_percentage`: Percentage of meal duration spent actively feeding (vs. time between visits)

#### `labeled_visits.rda`
R data file containing individual feed visits labeled with meal information (list of data frames, one per day).

**Structure:** List of data frames, where each data frame contains all columns from `clean_feed.rda` plus:
- `meal_id`: Meal identifier (0 = outlier/not assigned to any meal, >0 = assigned meal ID)
- `gap_to_previous`: Time gap to previous visit (seconds)
- `gap_to_next`: Time gap to next visit (seconds)

#### `meal_plots.rda`
R data file containing ggplot objects for meal visualization plots (list of plots, one per animal).

**Structure:** List of ggplot objects showing meal clusters over time for each animal. This is listed as gitignored in the .gitignore file due to large size.

#### `*.pdf`
Individual PDF files (one per animal ID) containing meal timeline visualizations showing visit patterns and meal clusters.

## 5_synchronicity_analysis

**Generated by:** `scripts/5_synchronicity_analysis.r`

This folder contains pair-wise synchronicity analysis results showing which animals feed/drink together and at neighboring bins.

### Files:

#### `feed_matrices.rda`
R data file containing second-resolution feed activity matrices (intermediate output from `matrix_process()`).

**Structure:** List of data frames (one per day), where each data frame has rows for each second of the day and columns for each animal-bin combination, with binary indicators of activity.

#### `water_matrices.rda`
R data file containing second-resolution water activity matrices (same structure as `feed_matrices.rda` but for water bins).

#### `combined_matrices.rda`
R data file containing second-resolution combined feed+water activity matrices (same structure as `feed_matrices.rda` but covering all feed and water bins).

#### `pair_feed_results.rda`
R data file containing detailed pair-wise feeding synchronicity matrices (list structure, one per day).

**Structure:** List containing three elements (each is a list of matrices, one per day):
- `bout`: Matrices showing number of synchronized bouts between each pair
- `total_time`: Matrices showing total synchronized time between each pair
- `avg_duration`: Matrices showing average bout duration between each pair

#### `pair_water_results.rda`
R data file containing detailed pair-wise drinking synchronicity matrices (same structure as `pair_feed_results.rda`).

#### `pair_combined_results.rda`
R data file containing detailed pair-wise combined feed+water synchronicity matrices (same structure as `pair_feed_results.rda`).

#### `neighbor_results.rda`
R data file containing detailed neighbor proximity synchronicity matrices (same structure as `pair_feed_results.rda`).

#### `pair_feed_df.rda`
R data file containing pair-wise feeding synchronicity summary as a tidy data frame (animals feeding at the same time, any bins).

**Structure:** Single data frame with columns:
- `animal1`: First animal ID in the pair
- `animal2`: Second animal ID in the pair
- `bouts`: Number of distinct feeding bouts where both animals were active simultaneously
- `total_time`: Total time (seconds) both animals were feeding together
- `avg_duration`: Average duration per synchronized bout (seconds)

#### `pair_water_df.rda`
R data file containing pair-wise drinking synchronicity summary as a tidy data frame (animals drinking at the same time, any bins).

**Structure:** Single data frame with the same columns as `pair_feed_df.rda` but for water drinking activity.

#### `pair_combined_df.rda`
R data file containing pair-wise combined feed+water synchronicity summary as a tidy data frame (animals active at any bin simultaneously).

**Structure:** Single data frame with the same columns as `pair_feed_df.rda` but for combined feed and water activity.

#### `neighbor_df.rda`
R data file containing pair-wise neighbor synchronicity summary as a tidy data frame (animals feeding/drinking at adjacent bins simultaneously).

**Structure:** Single data frame with columns:
- `animal1`: First animal ID in the pair
- `animal2`: Second animal ID in the pair
- `bouts`: Number of distinct bouts where both animals were at neighboring bins simultaneously
- `total_time`: Total time (seconds) both animals were at neighboring bins together
- `avg_duration`: Average duration per neighbor bout (seconds)

#### `neighbor_compare.rda`
R data file containing comparison of total co-occurrence vs. neighbor proximity for each pair as a tidy data frame.

**Structure:** Single data frame with columns:
- `animal1`: First animal ID in the pair
- `animal2`: Second animal ID in the pair
- `cooccurrence_time`: Total time active together (feeding OR drinking) at any bins (seconds)
- `neighbor_time`: Time active together at neighboring bins (seconds)
- `neighbor_ratio`: Ratio of neighbor_time to cooccurrence_time (0 to 1, higher = preference for neighboring bins)

## 7_feed_availability_analysis

**Generated by:** `scripts/7_feed_availability_analysis.r`

This folder contains feed availability analysis, detecting feed additions and calculating feed availability percentages at each visit.

### Files:

#### `feed_additions.rda`
R data file containing detected feed addition events at the **per-bin level** (list of data frames, one per day).

**Description:** This file records feed additions for each individual bin separately. When a farmer adds feed to the same bin multiple times in quick succession (within the `max_bin_time_gap` window, typically 1 hour), those rapid additions are aggregated into a single event for that bin. This is useful for analyzing feed availability at each bin.

**Example:** If feed is added to Bin 1 three times between 6:00-6:03am (10kg, 20kg, 15kg), this is recorded as one event: 45kg added to Bin 1 at 6:00am.

**Structure:** List of data frames, where each data frame contains:
- `bin`: Feed bin number
- `addition_time`: Timestamp when feed was first added in this event (POSIXct datetime)
- `date`: Date of addition (YYYY-MM-DD format)
- `weight_increase`: Total amount of feed added (kg) - sum of all rapid additions to this bin
- `start_weight`: Feed weight before addition (kg)
- `end_weight`: Feed weight after addition (kg)

**Note:** There are typically 1-2 feed addition events per bin per day (morning and evening feeding sessions).

#### `feed_events.rda`
R data file containing aggregated feed addition events at the **farm/barn level** (list of data frames, one per day).

**Description:** This file aggregates feed additions across multiple bins within a short time window into farm-level feeding events. When feed is added to different bins during the same feeding session (e.g., Bin 1 at 6:00am, Bin 2 at 6:05am, Bin 3 at 6:10am), these are combined into a single farm-level event. This captures the overall feeding session timing and total feed added across the entire barn.

**Example:** If feed is added to Bin 1 at 6:00am (50kg), Bin 2 at 6:05am (60kg), and Bin 3 at 6:10am (45kg), this is recorded as one farm-level event: 155kg added across all bins starting at 6:00am.

**Structure:** List of data frames, where each data frame contains:
- `event_time`: Timestamp when the feeding session started (first bin addition time) (POSIXct datetime)
- `date`: Date of event (YYYY-MM-DD format)
- `bins_affected`: Number of bins involved in this feeding event
- `total_weight_increase`: Total feed added across all bins in this event (kg)
- `bin_list`: List of bin numbers involved in the event

#### `availability.rda`
R data file containing feed availability analysis results (list structure).

**Description:** This file contains feed availability calculations for each visit. For each visit, the function matches it to the most recent feed addition event for that bin to find what was the total amoount of feed added to that bin, then calculates what percentage of feed remained when the animal visited.

**How it works:**

1. Each visit is matched to the most recent feed addition for that bin (from `feed_additions.rda`)
2. For visits early in a day (before any feed addition on that day), the function automatically matches to feed additions from the previous calendar day
3. Feed availability percentage is calculated as: `pct_feed_remaining = (start_weight / bin_weight_after_fill) × 100%`
   - `start_weight`: Feed weight in bin when visit started
   - `bin_weight_after_fill`: Feed weight in bin immediately after the most recent feed addition

**Structure:** List containing two elements:

- `visits`: List of data frames (one per day) with visit-level feed availability data:
  - All columns from `clean_feed.rda` (cow, bin, start, end, duration, intake, start_weight, end_weight, etc.)
  - `feed_addition_time`: Timestamp when feed was last added to this bin (POSIXct datetime)
  - `feed_added_weight`: Amount of feed added in the most recent addition (kg)
  - `bin_weight_after_fill`: Bin weight immediately after the most recent feed addition (kg). Note: This may differ from `feed_added_weight` because it includes residual feed already in the bin
  - `pct_feed_remaining`: Percentage of feed remaining when visit started (0-100%), calculated as `(start_weight / bin_weight_after_fill) × 100%`

- `daily_summary`: List of data frames (one per day) with daily summaries per animal:
  - `cow`: Animal ID
  - `date`: Date of observation (YYYY-MM-DD format)
  - `mean_pct_feed_remaining`: Mean percentage of feed remaining across all visits for this animal on this day
  - `median_pct_feed_remaining`: Median percentage of feed remaining across all visits (recommended for skewed distributions)
  - `sd_pct_feed_remaining`: Standard deviation of feed availability percentages
  - `total_visits_analyzed`: Total number of visits with valid feed availability data (visits where feed addition could be matched)

#### `all_visits_with_availability.rda`
R data file containing all visits across all days combined with feed availability percentages (single data frame).

**Description:** This is a convenience file that combines all visit-level feed availability data from `availability.rda$visits` into a single data frame for easier analysis across multiple days.

**Structure:** Single data frame with all columns from `availability.rda$visits` combined across all days. Contains the same columns as described in `availability.rda$visits` above.

## 9_filter_problematic_days

**Generated by:** `scripts/9_filter_problematic_days.r`

This folder contains filtered datasets where problematic days have been removed, along with intermediate data objects used for filtering. The filtering pipeline removes days affected by lameness, sickness, estrus, regrouping events, data quality warnings, and other confounding factors, leaving only clean records from pregnant cows in stable groups.

### Files:

#### `date_cow_list.rda`
R data file containing the base list of all cow-date combinations present in the raw cleaned feed data.

**Structure:** Data frame with columns:
- `date`: Date of observation (POSIXct)
- `cow`: Animal ID (integer)

#### `lameness_processed.rda`
R data file containing lameness status for each cow on each day, after updating gait scores and labeling lame periods.

**Structure:** Data frame with columns:
- `date`: Date of observation (POSIXct)
- `cow`: Animal ID
- `GS`: Original gait score
- `GS_updated`: Gait score after applying note-based corrections
- `GS_updated_fill`: Gait score with NA values filled between scoring events
- `current_lame`: Lameness label ("Y" = currently lame, "Q" = questionable, "N" = not lame)
- `ever_lame`: Whether the cow was ever lame during the study ("Y"/"N")
- `days_bf_lame`: Days before lameness onset (negative integers; NA if cow never became lame)

#### `DIM_parity.rda`
R data file containing Days In Milk (DIM), parity, and reproduction status for each cow on each day.

**Structure:** Data frame with columns:
- `date`: Date of observation (POSIXct)
- `cow`: Animal ID
- `Parity`: Lactation number
- `days_in_milk`: Days In Milk
- `updated_repro_status`: Reproduction status ("PREG", "BRED", "FRESH", "OPEN", etc.)

#### `milk_production.rda`
R data file containing daily milk production records for each cow.

**Structure:** Data frame with columns:
- `date`: Date of observation (POSIXct)
- `cow`: Animal ID
- `milk_production`: Daily milk yield (kg, sum of morning and afternoon milking)

#### `in_heat_processed.rda`
R data file containing estrus/heat status flags for each day.

**Structure:** Data frame with columns:
- `date`: Date of observation (POSIXct)
- `cow`: Animal ID
- `today_has_cow_in_heat`: Whether any cow in the group was in heat on this day ("Y"/"N")
- `cows_in_heat`: List of cow IDs in heat on this day

#### `repl_per_day.rda`
R data file containing the number of replacement events per day.

**Structure:** Data frame with columns:
- `date`: Date of observation (POSIXct)
- `replacement_num`: Total number of replacement events recorded on this day

#### `elo_full_result.rdata`
R data file containing the full Elo rating sequence object from the `EloRating` package.

**Structure:** Elo rating sequence object (as returned by `EloRating::elo.seq()`), computed from replacement events at low-to-medium feeder occupancy (≤0.75), excluding red and specific orange warning days.

#### `elo_score_daily.rdata`
R data file containing daily Elo scores for each cow.

**Structure:** Data frame with columns:
- `date`: Date of observation (POSIXct)
- `cow`: Animal ID
- `Elo`: Elo rating score for this cow on this day

#### `stable_groups.rda`
R data file containing the definition of stable groups between regrouping events.

**Structure:** Data frame with columns:
- `group_number`: Unique identifier for each stable group
- `start_date`: Start date of the stable group period (POSIXct)
- `end_date`: End date of the stable group period (POSIXct)

#### `days_per_group.rda`
R data file containing the number of valid days each cow has in each stable group (after all filtering).

**Structure:** Data frame with columns:
- `cow`: Animal ID
- `group_number`: Stable group identifier
- `days_count`: Number of valid days this cow has in this stable group

#### `max_days_group.rda`
R data file containing, for each cow, the stable group in which it has the most valid days of records.

**Structure:** Data frame with columns:
- `cow`: Animal ID
- `group_number`: Stable group identifier with the most days for this cow
- `days_count`: Number of valid days in that group

#### `group_frequency.rda`
R data file summarizing, for each stable group, how many cows have at least 13 valid days of records.

**Structure:** Data frame with columns:
- `group_number`: Stable group identifier
- `start_date`: Start date of the stable group (POSIXct)
- `end_date`: End date of the stable group (POSIXct)
- `cow_num`: Number of cows with ≥13 valid days in this group

#### `all_info_final.rda`
R data file containing the fully filtered dataset with all covariates merged, after applying all exclusion criteria. Each row represents one cow-day combination that passed all filters.

**Filtering steps applied (in order):**
1. Remove cow entry and exit days
2. Remove red warning days
3. Remove specific orange warning days with data loss
4. Remove regrouping days
5. Remove specific cow-date combinations with known data issues
6. Remove sick cow periods (±7 days around recorded sickness)
7. Remove lame cows and 7 days before lameness onset
8. Remove days when any cow in the group was in heat
9. Keep only pregnant cows (`updated_repro_status == "PREG"`)
10. Remove days with ≥900 replacements (herd-level anomalies)
11. Add stable group number to each record

**Structure:** Data frame with columns:
- `date`: Date of observation (POSIXct)
- `cow`: Animal ID
- `Parity`: Lactation number
- `days_in_milk`: Days In Milk
- `milk_production`: Daily milk yield (kg)
- `replacement_num`: Number of replacements on this day
- `Elo`: Elo dominance score
- `THI_mean`: Mean Temperature-Humidity Index
- `group_number`: Stable group identifier

#### `all_info_final_selected.rdata`
R data file containing the subset of `all_info_final` restricted to the top 3 stable groups with the most cows having ≥13 valid days of records.

**Structure:** Same columns as `all_info_final.rda`, filtered to records belonging to the selected stable groups.

## 10_synchronicity_analysis_breakdown

## 11_repeatability

**Generated by:** `scripts/11_repeatability.r`

This folder contains Bayesian repeatability analysis results for daily feeding and drinking behavior variables. A mixed-effects model is fitted for each response variable using `brms`, with DIM, DIM², parity, and THI as fixed effects, and individual cow and stable group as random effects. Repeatability (R) is estimated as the proportion of total variance attributable to between-individual differences.

**Model formula (per response variable):**
`response ~ DIM + I(DIM^2) + parity + THI_mean + (1 | cow) + (1 | group_number)`

**Response variables analyzed:** `feed_intake`, `feed_duration`, `feed_visits`, `water_intake`, `water_duration`, `water_visits`

### Files:

#### `m1_brm_<response_var>.rds`
Fitted `brms` model object for each response variable (one `.rds` file per variable, e.g., `m1_brm_feed_intake.rds`).

**Structure:** A `brmsfit` object (as returned by `brms::brm()`) with WAIC criterion added. Contains posterior samples, model formula, data, and diagnostics. Load with `readRDS()`.

#### `repeatability_summary.csv`
Summary table of repeatability estimates and individual-level coefficients of variation across all response variables.

**Columns:**
- `variable`: Response variable name (e.g., `feed_intake`)
- `R_cow_mean`: Posterior mean repeatability (proportion of variance due to individual cow differences)
- `R_cow_lower`: Lower bound of 95% HPD interval for R_cow
- `R_cow_upper`: Upper bound of 95% HPD interval for R_cow
- `R_group`: Posterior mean proportion of variance due to stable group
- `R_residual`: Posterior mean proportion of residual (within-individual) variance
- `CVi_mean`: Posterior mean individual-level coefficient of variation (CVi = SD_cow / grand mean)
- `CVi_lower`: Lower bound of 95% HPD interval for CVi
- `CVi_upper`: Upper bound of 95% HPD interval for CVi

#### `BT_plot_<response_var>.pdf`
Posterior distribution ridge plots for each response variable (one PDF per variable, e.g., `BT_plot_feed_intake.pdf`).

**Description:** Each plot shows the posterior distribution of the individual-level intercept (adjusted to the response scale) for every cow, ordered by posterior mean. The cow with the highest and lowest posterior mean are highlighted; all others are shown in gray.
